This is a 3D Dungeon Generator algorithm for Unreal Engine, exposed as a PCG node. While the port for Unreal required significant adaptation, the core idea is entirely based on this article by vazgriz:
https://vazgriz.com/119/procedurally-generated-dungeons/

and the related source code, originally for Unity, that is available here:
https://github.com/vazgriz/DungeonGenerator
